RBO 재고조사 웹앱 v1

[구성]
- index.html : 화면
- app.js : 재고조사 기능
- xlsx.full.min.js : 엑셀 읽기/저장 라이브러리
- rock.png : 화면 이미지
- manifest.webmanifest / service-worker.js : 홈 화면 설치(PWA) 및 오프라인 실행
- icon-192.png / icon-512.png / favicon.png : 아이콘

[사용 방식]
1. HTTPS 웹서버에 이 폴더의 파일을 모두 그대로 업로드합니다.
2. PC/휴대폰 브라우저에서 index.html 주소에 접속합니다.
3. 기준정보와 현재고 엑셀을 선택합니다.
4. 블루투스/USB 바코드 스캐너로 바코드를 찍습니다. 스캐너가 Enter를 같이 보내면 자동 집계됩니다.
5. 브라우저가 BarcodeDetector를 지원하면 '카메라 스캔' 버튼도 사용할 수 있습니다.

[새 바코드 대응]
- 9361541052035 같은 13자리 바코드는 그대로 정확 일치합니다.
- 0000070608 같은 앞자리 0 포함 바코드도 문자열 그대로 유지합니다.
- 기준정보가 0000070608인데 스캐너가 70608처럼 앞의 0을 생략해도, 동일 후보가 하나뿐이면 자동으로 매칭합니다.
- 서로 다른 길이의 바코드가 섞여도 예전처럼 평균 길이에 맞춰 0을 붙이지 않습니다.

[주의]
- 기준정보/현재고 파일 내용은 서버로 업로드되지 않고 브라우저에서만 처리됩니다.
- 중간저장은 브라우저 localStorage에 저장됩니다.
- 기준정보/현재고 자체는 새로 페이지를 열면 다시 선택해야 합니다.
- 카메라 스캔은 브라우저 지원 여부에 따라 사용할 수 없을 수 있습니다. 블루투스/USB 스캐너 입력은 일반 텍스트 입력 방식이라 폭넓게 사용할 수 있습니다.
